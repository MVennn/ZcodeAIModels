**单进程入口：路由、协议桥与两个本地网关的起停都交给 `gateways/zgate`，目录重新分层。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/ZcodeAIModels/issues/new/choose) 反馈 —— 请附上 ZCode 版本、provider 与模型、脚本与完整命令、输出原文。

## 本版内容

**统一入口**

- 新增 `gateways/zgate` —— 一个 Go 二进制监听 `127.0.0.1:7871`，四组模型照旧填空，`provider_config.json` 不用改。
- 变更 分流方式 —— 按 `model-alias-map.json` 把显示名还原到上游；文件改了自动热加载，不用重启。
- 新增 子进程托管 —— 两个网关都**随用随拉**：首个请求时拉起，空闲 5 分钟回收，平时一个都不占。
- 新增 签到窗口 —— 09 / 21 / 22 点前后自动唤醒对应网关跑签到与保活，跑完回收。
- 调整 内存占用 —— 从 4 个进程 293 MB 降到 3 个进程约 99 MB；只留入口时约 19 MB。
- 调整 无窗自启 —— zgate 按 GUI 子系统构建：登录自启零窗口、无乱码，日志只落文件；终端里 `status` 照常输出。
- 移除 旧的 Node 路由与 PowerShell 守护器（旧路由留在 `gateways/legacy-router/` 一个版本，可回退）。

**目录**

- 变更 按两轴分层 —— 会被启动的东西进 `gateways/`，手动执行的采集/探测脚本进 `providers/`，跨供应商工具留在 `tools/`。
- 变更 上游位置 —— `gateways/upstream/workbuddy`、`gateways/upstream/qoder`（仍是独立 clone，整目录不入库）。
- 调整 文档与模板里的全部路径；新增 [docs/ARCHITECTURE.md](https://github.com/MVennn/ZcodeAIModels/blob/main/docs/ARCHITECTURE.md) 记录这次改造。

**仓库**

- 新增 冒烟测试 `gateways/zgate/smoke_test.py` —— 四条通道 + 两种桥 + 流式各打一发，返回 PASS/FAIL。
- 新增 `zgate reload` —— 改策略 / 空闲阈值 / 签到窗口不用重启。
- 调整 CI —— 增加 Go 格式、构建与单元测试。

---

> 脚本会改你自己的 ZCode 配置文件，写前自动备份到同目录的 .bak-* 文件。
> 升级后如果入口没起，运行 `gateways/zgate/zgate.exe status` 看状态，或 `zgate.exe install` 重建登录自启。
> 模型价格、额度、倍率与可用性以服务商当时的说明为准；文档里的数字是快照，会过时。
