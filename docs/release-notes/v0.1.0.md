**首版：把 OpenCode-Go 套餐与 WorkBuddy2API 网关接进 ZCode —— 探测、同步、请求头注入三样齐了，文档也补齐了。**

## 本版内容

**OpenCode-Go**

- 新增 六个 provider —— 主力 / 免费 / 低耗 / 高耗 / 对话 / 响应；按「额度能撑多少输出」分档，对话走 Anthropic 协议、响应走 OpenAI responses 协议，其余走 chat 协议。
- 新增 新模型自动收录 —— 每天跑一次；拉齐四个来源的模型清单，逐个试协议，能用、价格不过线、没弃用的自动写进 ZCode 的配置，写前自动备份。
- 新增 请求头注入代理 —— 给不支持自定义头的客户端补上 OpenCode-Go 要求的会话头，默认监听 127.0.0.1:8787；API key 照旧填在客户端里，代理不碰。
- 新增 六个 provider 的模型清单 —— 21 个模型的协议归属、工具调用支持、关思考写法、价格与月额度，逐个列在参数矩阵文档里。

**WorkBuddy**

- 新增 三个 provider —— 免代 / 低代 / 高代；按积分倍率分三档，组内从便宜到贵排，共 30 个模型。
- 新增 真实请求体探测 —— 用 ZCode 实际会发的请求体去探，而不是裸请求体；失败会自动退到更简的写法重试，结果断点续跑、可以中断接着来。
- 新增 免代 / 低代 / 高代 三档的倍率与上下文对照 —— 哪个模型支持图片、上下文多大、能关思考、实测通不通，逐个列出来。

**仓库**

- 新增 根 README —— 这是什么、适用环境、怎么从刷价格表到同步进 ZCode 的三步、全部脚本清单、写配置会改哪几处、已知坑。
- 新增 机器协议 —— PROGRESS 按逻辑任务分家（历史上 13 个并行代理抢一个文件，互相覆盖过）、凭据只走环境变量、CodeGraph 有无的两种写法。
- 新增 文档索引与文档规则 —— docs/ 唯一索引、单一正本映射表、链接纪律、变更触发矩阵。
- 新增 踩坑总汇 —— 为什么某个模型在 ZCode 里 400 而 curl 能通、协议为什么放错就 400、探测为什么要隔 20 秒、免费池 429 到底是不是故障。
- 新增 排错手册 —— 模型列表不刷新、某个模型 400 / 503、探测报协议不支持、价格表过期、同步后配置被覆盖、代理端口被占用，七种现象各自的排查步骤与解法。
- 新增 维护流程 —— 价格表怎么刷（含当前没有生成脚本这个缺口）、探测多久跑一次、结果快照留多久、写配置前怎么备份与回退。
- 新增 第三方声明 —— WorkBuddy2API Panel（MIT）、OpenCode Go（商业服务）、ZCode（闭源客户端）的来源、许可与使用理由。
- 调整 仓库 —— 从原工作目录里拆成独立仓库，脚本按「长期运维 / 一次性探测 / 归档」分目录，行为零变更。
- 调整 仓库 —— 补上忽略规则：凭据、缓存、日志、大体积探测结果与字节码都不进版本库，源码与文档照进。

---

> 脚本会改你自己的 ZCode 配置文件，写前自动备份到同目录的 .bak-* 文件。
> 模型价格、额度、倍率与可用性以服务商当时的说明为准；文档里的数字是快照，会过时。
