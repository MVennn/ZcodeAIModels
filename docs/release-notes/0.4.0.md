## 本版内容

**统一入口**

- 新增 构建脚本 `gateways/zgate/build.py` —— 一条命令完成构建与校验；产物不是无窗版就直接报错退出，不会流到开机自启。
- 新增 产物校验 —— `--check` 随时确认当前 `zgate.exe` 是不是无窗版；`--cross-check` 在临时目录另编一份再验，CI 与 Linux 上都能跑。
- 调整 构建方式 —— `docs/MAINTENANCE.md` 的构建命令正本改为 `python gateways/zgate/build.py`；原有的 `go build` 命令仍然可用。

**修复**

- 修复 无窗构建被顶掉 —— 在 `gateways/zgate/` 里误跑单包 `go build .` 会把无窗版覆盖成控制台版、开机弹 cmd 窗口；现在构建走 `build.py`，产物当场校验。
- 修复 误判归因 —— 「`go build ./...` 会覆盖产物」的说法不准确：多包模式只编译不落盘，真正会覆盖的是单包 `go build .`；文档已订正。
- 修复 弹窗机制未写明 —— 快捷方式的「最小化」对控制台程序不等于隐藏，无窗与否取决于产物本身；机制与排错步骤已补进 `docs/PITFALLS.md` §20 与 `docs/TROUBLESHOOTING.md` §16。

**仓库**

- 调整 CI —— 增加一步产物校验，忘带无窗编译参数时流水线直接报错。
- 调整 工具清单 —— `docs/TOOLS.md` 登记新增的构建脚本。
- 调整 忽略规则 —— 排除 IDE 本地工作区目录 `.workbuddy/`；版本化记忆仍在本仓 `memories/`。
