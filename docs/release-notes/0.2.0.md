**同步脚本会主动清理上游已弃用的模型；价格表抓取与每日自动收录更稳。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/ZcodeAIModels/issues/new/choose) 反馈 —— 请附上 ZCode 版本、provider 与模型、脚本与完整命令、输出原文。

## 本版内容

**OpenCode-Go**

- 调整 模型同步 —— `--apply` 时直接移除上游明确弃用（410 / 弃用日期表）、端点不可用（402）或模型不支持（400）的模型，连同 `personalModelIds`、`modelOrder`、`modelConfigRules` 一起删掉，报告里写明上游原话。
- 调整 模型同步 —— 体检跳过 `cn:` / `global:` 开头的 WorkBuddy 模型（统一路由把它们转给网关，不属于 Go 套餐）。

**WorkBuddy**

- 调整 模型同步 —— 统一模式下，不再被选中的 `cn:` / `global:` 模型从配置删除；网关偶尔只返回部分模型时，缺失的模型保留并只报告，避免误删。
- 修复 价格表抓取 —— 读对 `can_disable_thinking` 字段；新表比旧表少 30% 以上时拒绝覆盖（需 `--force`）。

**自动化**

- 修复 每日自动收录 —— 重建为每天 12:00；取网关 key 的来源改为 `gateway/config.json`；目标会话解绑，每次运行新建独立会话。
- 调整 守护器 —— 主进程改用进程句柄判活；启动时对账清理遗留网关；停止时按端口反查并校验进程名；新增 15 分钟心跳。

**仓库**

- 新增 Issue 表单；凭据扫描覆盖全部脚本。
