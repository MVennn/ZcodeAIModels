# memories/ —— 本仓的「记忆」文档

> **一句话**：这里放**只靠读代码和文档读不出来的事实** —— 踩过的坑、根因、实测结论、
> 已确认但未修的缺陷。同样的内容也存在于 ZCode 的记忆库（按项目 id 分目录），
> 这里是**随 git 版本化的那份快照**。

## 为什么单独放一个目录

记忆和代码的寿命不一样：代码天天改，记忆是**一次次踩坑攒下来的**。
放进 `docs/` 会被淹没；放进记忆库又不在版本控制里、换台机器就没了。
所以两边各留一份：记忆库是活的（AI 每次开仓会读），这里是冻的（可 diff、可回溯）。

## 约定

- 一条一件事，一个文件，文件名 kebab-case。
- 开头写**结论**，不要写成流水账。
- 引用别处用 `[[记忆名]]`。
- 敏感值一律写 `<REDACTED-...>` 占位符；真值在设备上或密码管理器里。
- 新增后同步更新 [MEMORY.md](MEMORY.md) 索引。
